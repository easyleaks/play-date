🎮 GamerMatch

GamerMatch is an iOS application designed to connect gamers through two core experiences: • 🔥 Swipe-based social matching • 🎯 Live teammate finder (LFG mode)

The app combines social discovery with real-time squad formation in a minimal, dark-themed interface inspired by modern gaming platforms.

⸻

🚀 Concept

GamerMatch bridges the gap between traditional dating apps and gaming community tools.

Instead of separating social interaction and in-game coordination, the platform allows users to: • Discover people through swipe-based matching • Showcase favorite games and music in profile widgets • Find teammates instantly through structured live search • Connect only after mutual confirmation

⸻

🧩 Core Features (MVP Scope)

1️⃣ Social Matching • Swipe left/right system • Mutual match confirmation • Profile widgets: • 🎮 Favorite games • 🎵 Favorite music • 📝 Short bio • 📷 Profile photo • Private chat after match

2️⃣ Live Teammate Finder (LFG Mode) • Game selection • Mode selection (e.g., duo, squad, ranked, casual) • Real-time matchmaking request • Invite / accept confirmation system • Chat access after mutual approval

⸻

🎨 Design Philosophy • Dark-mode only • Black / deep gray base with purple accent • Minimalist layout • Widget-based profile structure • Native iOS feel using modern UI principles • Bottom tab navigation

⸻

🛠 Tech Stack • Swift • SwiftUI • Xcode • iOS (latest SDK) • Git for version control
